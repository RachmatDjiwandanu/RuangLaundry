# RuangLaundry — Company Profile Website

Website company profile dan landing page pemasaran resmi untuk **RuangLaundry**, penyedia solusi digital dan sistem pemesanan laundry online bagi para pemilik usaha laundry.

---

## Tech Stack
* **Framework:** React 19
* **Build Tool:** Vite 6
* **Styling:** Tailwind CSS 3 & PostCSS
* **Icons:** Lucide React
* **Typography:** Manrope (Google Fonts)
* **Architecture:** Component-Based Frontend Architecture (SPA)

---

## Perintah Pengembangan (Development Commands)

### 1. Instalasi Dependency
```bash
npm install
```

### 2. Menjalankan Server Lokal (Dev)
```bash
npm run dev
```

### 3. Build untuk Produksi
```bash
npm run build
```

### 4. Pratinjau Build Produksi
```bash
npm run preview
```
