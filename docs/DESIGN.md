# 1. DESIGN OVERVIEW

## 1.1 Design Philosophy

RuangLaundry Company Profile menggunakan pendekatan desain Modern Corporate yang menggabungkan profesionalitas perusahaan teknologi dengan kesederhanaan antarmuka SaaS modern.

Website harus memberikan kesan:

- Professional: menunjukkan identitas perusahaan yang serius dan terpercaya.
- Modern: mengikuti karakter website perusahaan teknologi masa kini.
- Clean: memiliki tampilan bersih, terstruktur, dan tidak berlebihan.
- Trustworthy: membangun kepercayaan calon pelanggan.
- Conversion-focused: mengarahkan pengunjung untuk melakukan konsultasi dan memilih paket layanan.

Desain tidak boleh terlihat seperti template landing page AI generik.

Setiap section harus memiliki tujuan komunikasi yang jelas, hierarki visual yang konsisten, dan tata letak yang mendukung pengalaman pengguna.

## 1.2 Design Principles

Terapkan prinsip berikut:

1. Clarity over Decoration: prioritaskan informasi dibandingkan elemen dekoratif.
2. Consistency: seluruh section harus menggunakan sistem desain yang sama.
3. Visual Hierarchy: headline, deskripsi, CTA, dan informasi pendukung memiliki prioritas visual yang jelas.
4. White Space: berikan ruang kosong yang cukup agar halaman tidak terasa padat.
5. Functional Animation: animasi hanya digunakan untuk mendukung interaksi.
6. Responsive First: seluruh komponen harus dirancang agar nyaman digunakan pada perangkat mobile.
7. Brand Consistency: pertahankan identitas visual RuangLaundry pada seluruh halaman.

# 11. RESPONSIVE DESIGN

Website wajib mendukung tiga kategori perangkat.

## 11.1 Breakpoints

| Device | Width |
|---|---|
| Mobile | < 640px |
| Tablet | 640px–1023px |
| Desktop | >= 1024px |

Gunakan breakpoint tambahan apabila dibutuhkan untuk menjaga kualitas layout.

## 11.2 Desktop Rules

- Gunakan two-column layout pada Hero.
- Navbar horizontal.
- Feature grid 3 kolom jika konten memungkinkan.
- Pricing grid 3 kolom.
- Container maksimal 1200px.
- Gunakan whitespace yang cukup.

## 11.3 Tablet Rules

- Sesuaikan ukuran heading.
- Kurangi jumlah kolom jika diperlukan.
- Pertahankan proporsi gambar.
- Hindari elemen terlalu rapat.
- Navbar dapat disederhanakan.

## 11.4 Mobile Rules

- Layout satu kolom.
- Navbar menggunakan hamburger.
- CTA mudah dijangkau.
- Tombol memiliki area sentuh minimal 44x44px.
- Heading tidak terpotong.
- Pricing cards disusun vertikal.
- Timeline menggunakan vertical layout.
- Foto hero tetap memperlihatkan kedua anggota tim.
- Tidak boleh ada horizontal overflow.

# 12. INTERACTION & MOTION DESIGN

## 12.1 Animation Principles

Animasi harus:

- Halus.
- Cepat.
- Tidak mengganggu.
- Memiliki tujuan.
- Konsisten.

## 12.2 Recommended Animations

- Fade-in saat section masuk viewport.
- Subtle hover pada card.
- Button hover transition.
- Accordion expand/collapse.
- Smooth scrolling.
- Navbar transition.

## 12.3 Motion Restrictions

Hindari:

- Animasi yang terlalu sering.
- Parallax berlebihan.
- Infinite floating animation.
- Efek bouncing pada setiap elemen.
- Scroll hijacking.
- Animasi yang mengganggu pembacaan.

Hormati prefers-reduced-motion.
